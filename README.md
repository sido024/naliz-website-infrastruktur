# 💈 NALIZ – IT-Infrastruktur & Web-Hosting

Dieses Projekt beinhaltet das Frontend sowie die geplante Linux-Webserver-Infrastruktur und Automatisierung für den Dienstleistungsbetrieb **NALIZ** (Make-up • Hair • Hijab).

---

## 🎯 Projekt- & FISI-Fokus

- **Frontend & UI:** Responsive Web-Oberfläche für Termin-Anfragen mit benutzerdefiniertem NALIZ-Farbkonzept und interaktivem JavaScript-Modal.
- **Systemintegration (In Arbeit):**
  - Webserver-Deployment (Nginx auf Linux)
  - Domain- & DNS-Konfiguration
  - SSL-Absicherung (HTTPS via Let's Encrypt / Certbot)
  - Backup- & Monitoring-Automatisierung
